# AegisShare — Platform Sections (10)

| Section | What it does |
|---|---|
| Command Center | Real-time dashboard — files protected, policy decisions/24h, open threats, audit events, live Kafka event stream, 28-day anomaly baseline |
| Secure Vault | File management with full crypto provenance per file; 4-step encryption walkthrough on upload |
| Compliance Hub | Certification dashboard across GDPR/HIPAA/SOC2/CCPA/ISO27001 with per-control evidence and signed reports |
| Policy Engine | ABAC rule editor + RBAC role matrix + live OPA Rego source + PDP simulator with evaluation trace |
| Audit Ledger | Merkle-chain visualization, chain-integrity verification badge, filterable event log, RFC 5424 structured events |
| Threat Center | P1-P4 threat cards, 28-day anomaly baseline (3-sigma ML scoring), IP reputation/ASN/geo intelligence |

| Settings | 4-panel config (Encryption/Zero-Trust/Audit/Sovereignty), compliance-locked controls, Danger Zone |
| Admin Console | L4+ only, visually distinct (gold/Cinzel) — system health, incidents, user mgmt, sovereignty, licensing, backup/recovery, admin audit log |
