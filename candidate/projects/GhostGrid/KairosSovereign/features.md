# Kairos Sovereign — Key Features

- Unifies Ghost Grid, Phantom Strike, VOID ENGINE, POLM, and
  ARBITER-Sigma into one doctrine
- Temporal Bias Budget — makes the adaptivity/rigor trade-off a
  measured, weekly-controlled variable instead of a design assumption:
  `Temporal Bias Budget = f(regime_volatility, adaptation_speed_required)`
- Adversarial Red Team runs 24/7 against the system's own patterns
  before the market does
- Phoenix Recovery Protocol — explicit resumption procedure after every
  circuit-breaker trip
- Every component has a Minimum Viable equivalent it degrades to rather
  than stopping signal production entirely
