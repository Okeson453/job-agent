# POLM — Challenges & Solutions

**The problem each legacy lineage had alone:** Box Theory produces
false reversals in trending markets; ORB produces fakeouts and
over-chasing; AVB alone has regime ambiguity. POLM's answer is
cross-validation — no protocol fires unless all relevant sub-systems
agree, via the MF-RCE gate.

**v1.1's honesty upgrade:** the doc explicitly frames v1.0's EV claims
(a flat "+33R/month" point estimate) as a problem it fixed, not a
feature — v1.1 replaced every theoretical projection with realized,
rolling, confidence-interval-bounded performance tracking. Worth
citing as an example of catching your own overconfident claims.

**Still open:** the Ghost Grid and Phantom Strike integration points
described in architecture are Phase 3 (v2.0) roadmap items, not built
yet — POLM today has no automated connection to either engine.
