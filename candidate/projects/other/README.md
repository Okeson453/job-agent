of these matures into a real portfolio piece, give it its own
PascalCase directory using the same file set as the fully-scaffolded
projects (see e.g. `../GhostGrid/PhantomStrike/`) as your template.

  entry point), containing `PhantomStrike/`, `KairosSovereign/`,
  `EchoPulse/`, `VoidEngine/`, `POLM/`, `ArbiterSigma/` as sub-projects
- `../OrionSentinel/`, `../Crash/` (CrashWave), `../TestingEngine/`,
  `../SentraAura/`
- AegisOS (+AegisTriage, +AegisShare) — `../AegisOS/`
- MPP and HLCP trading strategies — `../../skills/trading.yaml`
